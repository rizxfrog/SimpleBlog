7) 关键写入流程（Git 行为）
   7.1 初始化 doc（创建 main 分支指向空 or 初始 commit）

创建 doc

创建首个 commit（无 parent）

创建 doc_ref(main) 指向该 commit

写入 doc_head head_ref=main

7.2 普通提交（在某分支上提交）

输入：branch_ref, base_commit（客户端看到的 tip），title, content_md, message

事务内：

锁住该 ref 行（或 CAS ref_version）

校验 ref 当前 tip == base_commit（否则提示 “non-fast-forward”）

insert doc_commit（child）

insert doc_commit_parent（child -> base_commit）

update ref 指向 child

7.3 合并（merge）

合并 commit 通常有 2 个 parent：

parent0 = target 分支 tip（first parent）

parent1 = source 分支 tip

内容：你可以让前端做 merge 冲突解决后提交 merge commit（最简单、实现成本最低）。
事务内：

锁 target ref

读 target tip 与 source tip

insert merge commit（content 是合并后的 md）

insert parents 两行（order 0/1）

update target ref 指向 merge commit
